# persian-resources

A landing page linking to three small Persian-learning tools: [noghteh](https://github.com/jkcog/noghteh), [harf-bezan](https://github.com/jkcog/harf-bezan), and [finglish-subs](https://github.com/jkcog/finglish-subs).

Static HTML, no build step. **[View the page](https://jkcog.github.io/persian-resources/)**.

To preview locally: `python3 -m http.server` and open `http://localhost:8000`.

## Setup note

GitHub Pages needs to be turned on once for this repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`**.
